## 🧠 Problem Statement

Early user churn significantly impacts product growth and long-term retention.

This system analyzes **first 48-hour behavioral signals** to:

- Predict long-term user retention
- Identify churn-risk users early
- Enable automated intervention strategies
- Reduce dependency on manual analytics
